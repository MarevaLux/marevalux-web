# MarevaLux Web

Sitio institucional de MarevaLux desarrollado con Next.js y Tailwind CSS.

## Abrir el proyecto localmente

1. Abrí la carpeta `marevalux-web` en Visual Studio Code.
2. Abrí una terminal desde `Terminal > New Terminal`.
3. Instalá las dependencias:

```bash
npm install
```

4. Iniciá la página:

```bash
npm run dev
```

5. Abrí [http://localhost:3000](http://localhost:3000) en el navegador.

## Comandos útiles

```bash
npm run dev
npm run lint
npm run build
```

- `npm run dev`: trabaja sobre la web en modo local.
- `npm run lint`: revisa posibles errores del código.
- `npm run build`: confirma que la página está preparada para publicarse.
